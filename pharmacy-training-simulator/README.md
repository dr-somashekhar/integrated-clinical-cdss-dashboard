# PharmaDesk Pro - Pharmacy Software Training Simulator

A **dummy**, fully offline pharmacy-management simulator for classroom training.
Open `index.html` in any browser (double-click). No server, no internet, no installation.

- All data is fictional and is stored only in the browser (localStorage). Nothing is transmitted anywhere.
- Not for real patient care, real dispensing, publication or commercial use.
- Utilities > Reset Training Data restores the original sample data.

Screens: Dashboard, New Prescription (with allergy / interaction / duplicate / stock / age alerts), Rx workflow queue
(Fill > Verify > Dispense with labels and bill), Retail billing (POS), Inventory & batches, Purchase entry (GRN),
Patient / Prescriber / Supplier masters, Reports (sales, stock, expiry, low stock, Schedule H/H1 register), Training Guide
with 11 exercises. Click any field to see a hint about what to enter. Shortcuts: F1 guide, F2 Rx, F3 queue, F4 billing,
F6 inventory, F7 patients, F8 reports, F9 save.
